# v2.1 相对 v2.0.2 的更新报告

v2.1 是当前推荐的完整 Skill 快照，标签对应提交 `3bced5ed2099d9e6ea33fc88d0fe4217f8397e87`。技能根目录名称仍为 `paper-to-html-v2`，版本号和目录名称不必相同。

## 主要变化

| 项目 | v2.0.2 | v2.1 |
|---|---|---|
| 逐面板带读 | 已有讲解规范，但装配缺少完整教学对象约束 | 增加逐面板讲解要求，保留当前问题与数据构造、局部图例、实际观察到判断、遗留问题四个区域 |
| 装配和发布检查 | 原有组件与发布检查 | 构建和发布调用教学结构检查，防止完整带读被简短 explain 段替代；明确结构通过不证明科学正确性 |
| 术语选择 | 缺少独立的术语选择与知识卡说明 | 从当前论文发现候选，再选择、消歧与解释；旧词库仅辅助核对，未命中不是忽略理由 |
| 知识卡解释 | 既有卡片与返回交互 | 明确概念定义、工作关系、用法、本文角色和边界；引入相关概念前交代关系，避免无依据转场 |
| 术语分类 | 既有领域类别 | 默认使用对象、实体、过程、方法、指标、结构六类通用类别，同时保留历史类别兼容 |
| 链接处理 | 既有文本链接 | 新增文本节点匹配器，支持别名、拼写变体、长表达优先和作用域消歧；避免替换属性、脚本、已有链接和代码 |
| 查阅入口 | 既有知识卡跳转 | 原文、译文、图注均可提供适当查阅入口；支持卡片内部子条目定位和返回 |
| 验证 | 原有组件、服务与发布验证 | 增加8项概念匹配测试及8项讲解要求测试，分开报告匹配、结构、来源核对与理解效果 |

两版本之间的仓库历史还包含英文演示内容和英文截图。演示使用原创模拟内容，不包含用户论文全文或私人笔记；它与中文共读默认交付独立。

## 版本边界

按归档要求，v2.1 保存本科读者起点及进一步跨领域修订**之前**的版本。随后完成的“本科基础知识筛选、真实章节与论证类型适配、取消固定段落/图例数量门槛”等修改不在这个包中，不作为 v2.1 已有功能宣传。

v2.1 的结构检查仍有固定数量门槛，读者起点仍有待优化。自适应概念发现由制作助手的语义判断完成，匹配器不是自动发现器；测试通过也不表示任意学科已验证或读者理解已测得。后续正式发布版本应单独记录这些改进，并保留 v2.1 快照。
