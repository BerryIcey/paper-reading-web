# v2.2 相对 v2.1 的更新报告

v2.2 于2026年10月15日正式发布，设为最新推荐版。发行包、解压根目录与技能调用名统一为 `paper-to-html-v2.2`；v2.1 原包和历史标签保持不变。

## 主要变化

| 方面 | v2.1 | v2.2 |
|---|---|---|
| 读者起点 | 已有适配原则，基础概念容易过选 | 默认完成相关专业本科课程；结合知识缺口、阅读影响和回查价值选词，不建立全球基础词黑名单 |
| 术语与知识卡 | 从文章发现、消歧与解释 | 补足起点推定、纳入/排除依据、有限前置依赖与具体主张来源；词库和数据库仅辅助核对 |
| 跨领域论证 | 主要从实证文章经验提炼 | 按实证、推导/证明、算法/系统及概念/文本适配；递进、并行、反证和终点整合分别解释，清理底层冲突 |
| 核心范围 | 以正文与主图为主要检查入口 | 表格、公式、算法和证明承载主贡献时进入核心清单，与最终页面锚点逐项核对 |
| 讲解结构 | 段落和图例有固定数量门槛 | 取消数量配额；简单图可短，图例不适用须说明，充分性单独做语义审查 |
| 来源核对 | 已有来源台账 | 增加论文身份、版本、更新状态及主张—来源片段—网页锚点的追踪；区分缺报告、缺资料和反对证据 |
| 阅读显示 | 纯文献编号去除不是完整的统一要求 | 明确去除原文、译文、图注及讲解中的纯文献编号/引用角标，不换成另一种编号；保留科学上标及必要图号引用 |
| 交互 | 鼠标/触控预览、面板切换 | 图片可用Enter/空格打开，关闭后返回焦点；面板键盘顺序、预览alt和控件名称更完整，保留图片比例 |
| 外部能力 | 缺少统一的按需选用路径 | 借鉴科学审读、引用管理、网页规范与Skill创作方法；需要时检索候选，核对来源、许可与依赖，不强制安装外部工具包 |

## 引用角标规则已确认包含

包内以下四处均已核对：

- `SKILL.md`：所有阅读内容移除纯参考文献编号及引用上标角标，不改成其他编号形式。
- `references/reading-and-teaching.md`：包括逗号分隔编号与编号范围；只删除已确认的文献引用。
- `references/acceptance.md`：将这一点列为交付检查。
- `assets/AGENTS-reading.md`：新论文项目继续遵守同一规则。

图号、补充材料位置、数量、统计、单位、数学/化学上标、表型符号和实质说明脚注仍保留。来源在原论文与内部台账中保存，教学解释可使用有名称的来源链接。

## 验证及实际边界

18项Python unittest及装配、隔离笔记/并发保存、来源PDF路由、服务恢复和版本保留测试通过；真实浏览器回归验证键盘预览、焦点返回、面板导航和窄屏图片比例。测试使用原创合成页面，不包含用户论文或私人笔记。仓库CI现对v2.2运行回归，CI实际状态以GitHub Actions为准。

这些检查不证明每篇论文的科学解释、所有领域迁移、用户学习效果或完整WCAG符合性。独立真实论文迁移仍待进一步测试。默认保留用户批准的带点版本调用名；部分通用Skill校验器只允许连字符，会报告命名兼容项，不宣称该项通过。

外部方法的来源、固定版本和适配取舍见[外部能力选用](../skills/paper-to-html-v2.2/references/optional-capabilities.md)；数据库选择与证据流程见[来源与证据核对](../skills/paper-to-html-v2.2/references/source-and-evidence.md)。这些内容直接包含在Skill中，不要求先安装find-skills、整套科学工具或付费API。
