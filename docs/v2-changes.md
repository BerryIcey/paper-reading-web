# v2.0.1 相对 v1.0.0

v1独立冻结，v2是其更新版，不混用参考文件。

- 入口按范围、操作流程、四区、交互、文件与边界整理；去掉按日期追加的“最新/替代”补丁式规范。
- 目录导航与知识临时查阅分开；统一笔/图例同一行、默认标黄关闭与动作按钮文字。
- 核对证据先于自然解释；来源位置保存在台账，不在阅读示例里重复显示制作提示。
- 首次核心的完整翻译范围明确，Methods/附图按需；读者评议默认必需且全文末尾。
- 项目备份策略单一来源；离线只展示导出时设置，修改进入本地项目服务。
- 未配置备份时发布工作版，不清历史；0/1/2备份、单调版本号、桌面同名覆盖、内嵌资源校验和失败保留旧备份。
- 明确当前没有断线自动补存、跨设备队列同步或即时GPT，不把设计计划写成已实现功能。
- 原教学手册与校准案例保留，不为了精简入口删掉逐面板推理要求。

验证覆盖组件装配、笔记并发/编辑历史、健康/PDF/来源限制、服务子进程恢复、发布保留数量与失败情况。模拟浏览器视口不代替真机触控或全新论文端到端教学测试。

发布前同步界面元数据的v2名称与调用入口，删除已取消的续读记录措辞。
