# v2.2 changes from v2.1

Released on 15 October 2026 as the latest recommended version. The ZIP, its single root folder and invocation use `paper-to-html-v2.2`. The v2.1 package and historical tag are retained unchanged.

## What changed

- **Reader baseline:** Assume relevant undergraduate coursework, not expertise in the paper's specialty. Select concepts by knowledge gap, impact on understanding and lookup value, without a global basic-word blacklist.
- **Cross-domain reasoning:** Adapt to empirical, formal, algorithmic and conceptual arguments. Explain sequential, parallel, definitional and final-synthesis relations; remove conflicting experimental-only requirements.
- **Core coverage:** Include contribution-bearing tables, equations, algorithms and proofs in the source-derived coverage inventory, with final-page anchors.
- **Teaching depth:** Remove fixed paragraph and legend-row counts. Simple panels can be short; a non-applicable legend needs an explicit reason. Semantic adequacy remains a separate review.
- **Source checks:** Verify article identity/version and link important claims to source passages. Distinguish missing reporting, unavailable material and contrary evidence.
- **Citation display:** Remove bibliographic number markers and superscripts from displayed source text, translations, captions and explanations. Do not convert them into another numbered format. Preserve figure/supplement references, quantities, statistics, units, formula/chemical superscripts, phenotype signs and substantive footnotes. The source ledger and original paper retain provenance.
- **Keyboard access:** Open image previews with Enter/Space; restore focus on close. Improve panel tab order, preview alternative text, control names and aspect-ratio handling.
- **Optional capabilities:** Incorporate selected scientific appraisal, citation-management and web-interface practices. Extra Skills/databases are used for concrete gaps, not mandatory for every paper.

The citation-marker policy is present in `SKILL.md`, `references/reading-and-teaching.md`, `references/acceptance.md` and `assets/AGENTS-reading.md`.

## Validation limits

18 Python unittest cases and assembly, isolated note persistence/concurrency, PDF routes, supervisor recovery and release-retention checks passed. A real-browser synthetic fixture checks keyboard preview, focus return, panel navigation and narrow-screen image ratios. CI now targets v2.2; GitHub Actions reports the actual remote status.

These checks do not establish scientific accuracy for a paper, universal disciplinary transfer, learner outcomes or complete WCAG compliance. Independent transfer testing on real papers remains incomplete. The approved dotted version name is retained; generic Skill validators that allow hyphens only report this naming incompatibility.
